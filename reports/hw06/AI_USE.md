   collection logic, memory-service functions, file-based memory commands, and
   experiment scripts. I performed the terminal runs, reviewed the outputs, and
   captured the screenshots myself.

   containing unsupported course-specific vulnerability claims. I did not use
   those claims as experimental evidence.

3. I detected the problem by comparing generated responses with the actual
   assignment requirements and by checking the persisted MongoDB documents,
   API responses, token logs, and benchmark output files.

4. I changed the implementation and report to rely on observable evidence:
   stored messages, summaries, episodes, fixed probe questions, recorded token
   counts, latency values, validation responses, and file-memory command outputs.
   The final analysis labels probe scores as rubric-based measurements instead
   of treating generated text as proof of correctness.
